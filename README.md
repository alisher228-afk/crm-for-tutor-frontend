# CRM for Tutor — Frontend Client

Клиентская часть веб-приложения **«CRM for Tutor»** (CRM-система для репетиторов и личный кабинет учеников).  
Разработана на React, TypeScript, Tailwind CSS v4 и shadcn/ui. Backend реализован на Java / Spring Boot.

---

## 🛠 Стек технологий

- **Фреймворк и сборка:** [React 19](https://react.dev/), [Vite](https://vitejs.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Стилизация:** [Tailwind CSS v4](https://tailwindcss.com/)
- **UI-библиотека:** [shadcn/ui](https://ui.shadcn.com/) (с @base-ui/react)
- **Роутинг:** [React Router v7](https://reactrouter.com/)
- **Запросы и кэширование:** [TanStack Query v5](https://tanstack.com/query/latest) (@tanstack/react-query)
- **HTTP-клиент:** [Axios](https://axios-http.com/) (с автообновлением токена через refresh token interceptor)
- **Уведомления:** [Sonner](https://sonner.emilkowal.ski/)
- **Иконки:** [Lucide React](https://lucide.dev/)

## 👥 Роли пользователей и разделы системы

### 1. Репетитор (`TUTOR`) — Полноценная CRM-панель
- **/tutor/students** — Управление базой учеников:
  - Список с поиском и пагинацией
  - Добавление и редактирование ученика (почасовая ставка, уровень, контакты)
  - Детальная карточка, архивация
  - Генерация инвайт-ссылки для регистрации и кода привязки Telegram-бота
- **/tutor/lessons** — Интерактивное расписание занятий:
  - Фильтры («Эта неделя», «Следующая неделя», произвольный диапазон)
  - Группировка занятий по дням недели
  - Запланировать урок (выбор ученика, проверка наложения по времени)
  - Смена статуса (`SCHEDULED`, `COMPLETED`, `CANCELLED_BY_TUTOR`, `CANCELLED_BY_STUDENT`)
  - Ссылки на видеовстречи
- **/tutor/payments** — Учёт финансов и аналитика:
  - История оплат по выбранному ученику с автоматическим пересчетом баланса уроков
  - Добавление и редактирование платежей (сумма, количество оплаченных уроков, дата, заметка)
  - Вкладка «Аналитика дохода» по месяцам и годам (общий доход, средний чек, количество уроков и оплат)
- **/tutor/homework** — Управление домашними заданиями:
  - Выдача заданий ученикам с привязкой к уроку и установкой дедлайна
  - Прикрепление и скачивание файлов (drag-and-drop, валидация размера до 50 МБ)
  - Просмотр сданных работ и отметка «Проверено»

### 2. Ученик (`STUDENT`) — Личный кабинет (Read-only с возможностью сдачи ДЗ)
- **/student** — Профиль ученика:
  - Карточка текущего баланса уроков с индикатором необходимости пополнения
  - Персональные данные, контакты, информация о преподавателе
- **/student/lessons** — Моё расписание:
  - Список уроков с фильтром по неделям/периодам в едином визуальном стиле с репетитором
  - Кнопка прямого подключения к онлайн-занятию
  - Без прав редактирования (только просмотр)
- **/student/homework** — Мои домашние задания:
  - Интерактивные фильтры по статусам («Все», «Нужно сдать», «На проверке», «Проверено»)
  - Детальная карточка с дедлайном и материалами
  - Скачивание файлов задания и прикрепление файлов своего решения
  - Форма сдачи решения (комментарий + кнопка «Сдать»)
- **/student/payments** — История оплат и баланс:
  - Сводка по текущему остатку занятий и сумме внесенных средств
  - Таблица платежей (только просмотр)

## ⚙️ Переменные окружения (.env)

Приложение взаимодействует с REST API бэкенда через базовый URL, настраиваемый через переменную:

| Переменная | Описание | Пример для локальной разработки | Пример для продакшена |
|---|---|---|---|
| `VITE_API_BASE_URL` | Базовый URL бэкенда Spring Boot | `http://localhost:8081` | `https://api.your-backend-domain.com` |

Файлы конфигурации:
- `.env` — настройки для локальной разработки (по умолчанию `http://localhost:8081`)
- `.env.production` — шаблон настроек для production-сборки

## 🚀 Запуск проекта локально

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   cd crm-for-tutor-frontend
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Убедитесь, что в файле `.env` указан доступный адрес бэкенда:
   ```env
   VITE_API_BASE_URL=http://localhost:8081
   ```

4. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:5173`.

---

## 📦 Сборка для продакшена

1. Выполните сборку проекта:
   ```bash
   npm run build
   ```
   Сборщик скомпилирует TypeScript (`tsc -b`) и соберет оптимизированный bundle в папку `dist/`.

2. Для локальной проверки собранного бандла выполните:
   ```bash
   npm run preview
   ```

## 🌐 Деплой на хостинг (Vercel / Netlify / Cloudflare Pages)

### Важно перед деплоем!
Перед сборкой на хостинге **обязательно добавьте переменную окружения** в панели управления вашего проекта:
- **Key:** `VITE_API_BASE_URL`
- **Value:** `https://ваш-реальный-домен-бэкенда.com` (без слэша на конце)

### 1. Деплой на Vercel
1. Импортируйте репозиторий в Vercel.
2. Framework Preset определится автоматически как **Vite**.
3. В разделе **Environment Variables** добавьте:
   - `VITE_API_BASE_URL` = `https://ваш-бэкенд.com`
4. Нажмите **Deploy**. В репозитории уже присутствует файл [`vercel.json`](file:///C:/Project/crm-for-tutor-frontend/vercel.json), настроенный для корректной маршрутизации SPA (Single Page Application) без ошибок 404 при перезагрузке страниц.

### 2. Деплой на Netlify
1. Создайте сайт из Git-репозитория.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. В разделе **Site configuration -> Environment variables** добавьте:
   - `VITE_API_BASE_URL` = `https://ваш-бэкенд.com`
5. В папке `public/` уже размещен файл [`_redirects`](file:///C:/Project/crm-for-tutor-frontend/public/_redirects), обеспечивающий правильный роутинг страниц в Netlify.

## 📁 Структура проекта

```
src/
├── api/          # Axios-клиент и эндпоинты (auth, students, lessons, payments, homework, attachments)
├── components/   # Переиспользуемые компоненты (HomeworkAttachments, UI-библиотека shadcn)
│   └── ui/       # Базовые компоненты shadcn/ui (Button, Dialog, Sheet, Table, Tabs и др.)
├── context/      # React Context (AuthContext: авторизация, токены, рефреш-сессия)
├── hooks/        # React Query хуки (useStudents, useLessons, usePayments, useHomework, useAttachments)
├── layouts/      # Layout-обертки (TutorLayout со складным sidebar, StudentLayout)
├── pages/        # Страницы приложения
│   ├── auth/     # Логин, регистрация тьютора, регистрация ученика по инвайту
│   ├── tutor/    # Разделы репетитора (ученики, расписание, финансы, ДЗ)
│   └── student/  # Разделы ученика (профиль, расписание, ДЗ со сдачей, оплаты)
├── routes/       # Конфигурация маршрутов и ProtectedRoute с ролевым доступом
├── types/        # TypeScript интерфейсы и типы данных
└── index.css     # Стилизация Tailwind CSS v4
```
